# L'Atelier Web Auvergne

> Site vitrine de **L'Atelier Web Auvergne** — création de sites internet pour artisans et TPE à Clermont-Ferrand et en Auvergne.

🌐 **Site en ligne** : [latelier-web-auvergne.vercel.app](https://latelier-web-auvergne.vercel.app)

---

## 📂 Structure

```
latelier-web-auvergne/
├── index.html              # Page d'accueil (one-page complet)
├── mentions-legales.html   # Mentions légales (LCEN + RGPD conformes)
├── vercel.json             # Configuration Vercel (headers sécurité, cache)
└── README.md               # Ce fichier
```

Site **100 % statique** — aucune dépendance, aucun build, aucune base de données.

---

## 🎨 Stack technique

- **HTML5** + **CSS3** vanilla (aucun framework)
- **Fraunces** (titres) + **Geist** (texte) — fonts Google
- **JSON-LD `ProfessionalService`** pour le SEO local
- **Hébergement** : Vercel (CDN edge global)

## 🚀 Déploiement

Le site est déployé sur Vercel et se met à jour automatiquement à chaque push sur la branche `main`.

```bash

npx vercel deploy --prod
```
